GEO DIGITAL CONTACT LANDING PAGE
================================

FILES
-----
index.html
style.css
script.js
images/

HOW TO USE
----------

1. Put all three files in the same folder:
   - index.html
   - style.css
   - script.js

2. Open index.html in your browser.

3. Put your profile image inside the "images" folder.

4. In index.html, find:

   <img
       id="profileImage"
       src="images/profile.jpg"

   Replace "profile.jpg" with your actual image filename.

5. In index.html, find the PERSONAL INFORMATION section.

   Replace these placeholders:

   name: "Geo"
   phone: "+63 9XX XXX XXXX"
   personalGmail: "yourpersonal@gmail.com"
   businessGmail: "yourbusiness@gmail.com"

   instagram: "https://www.instagram.com/yourusername/"
   tiktok: "https://www.tiktok.com/@yourusername"

6. Save the files and open index.html again.

WHAT THE BUTTONS DO
-------------------

Contact Number:
- Call Number opens the phone dialer on supported devices.
- Save Number creates a .vcf contact file.

Instagram:
- Open Instagram opens your profile.
- Copy Link copies your profile link.

TikTok:
- Open TikTok opens your profile.
- Copy Link copies your profile link.

Gmail:
- Send Email opens the user's mail application.
- Copy Gmail copies the email address.
